# Gabriel Automações — Portfólio Interativo

Site estático em HTML, CSS e JavaScript puro, preparado para GitHub Pages.

## Recursos
- Landing page responsiva e profissional
- Demonstração local de atendimento de clínica com contexto e intenções
- Simulador funcional de reposição inteligente
- Jornada guiada de qualificação imobiliária com painel de CRM
- Nenhuma API, banco de dados ou n8n necessário nesta versão
- Nenhum dado real utilizado nas demonstrações

## Publicar no GitHub Pages
1. Crie um repositório novo no GitHub.
2. Envie `index.html`, `styles.css` e `script.js` para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`.
6. Salve e abra a URL criada pelo GitHub Pages.
