# Zion Automações — Site V11

Versão comercial interativa em HTML, CSS e JavaScript puro, pronta para GitHub Pages.

## Novidades da V11
- Jornada personalizada por segmento
- Personalização por URL (`?segmento=clinica&empresa=Nome`)
- Relatório pós-demo
- Diagnóstico comercial no estimador
- Recomendação do que automatizar primeiro
- Copiar/compartilhar estimativa
- Modo apresentação guiada
- CTA contextual no desktop
- Eventos locais preparados para analytics
- Open Graph com imagem da Zion

As demos continuam locais, sem n8n, backend ou dados reais.
